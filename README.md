# FASTQ Sonifier — public web release

This repository is the deployment-only front end for the public GitHub Pages edition of FASTQ Sonifier.

**Live app:** <https://narcherna.github.io/fastq-sonifier-app/>

The complete development repository remains private. This public repository contains only the browser files GitHub Pages must serve. It contains no FASTQ files, sequencing datasets, sample identifiers, or experiment exports.

FASTQ processing happens locally in the visitor's browser. Selected sequence and quality data are not uploaded to the application. Crystal Clear, Quality Crash, and Pattern Storm are wholly synthetic, deterministic, and generated locally only when selected.

The anonymous page-view display shares one aggregate counter with the official Sites edition. Its request has no body, credentials, cookies, referrer, sequence data, file names, settings, or fingerprints. The number counts page loads, not unique visitors.
